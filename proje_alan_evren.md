# AlanEvren · 1000 Fert

**Çoklu-fert alan dinamiği teorisinin App Store hedefli inşa hattı.**

## Tek cümle

1000 fertten oluşan kart-tabanlı alan dinamiği görselleştirme ve etkileşim
uygulaması; teori + uygulama beraber, App Store yayın hattı kurulu.

## İçerik

- **App** — kullanıcı tarafı arayüz
- **AppStore** — yayın hattı dosyaları (App Store Connect ön-hazırlık)
- **fertler** — 1000 fert kataloğu (kart-tabanlı veri)
- **`_core`** — çekirdek matematik motor
- **`_promptbol.py`** — içerik üretim altyapısı
- **`_uretici.py`** — kart üretim hattı
- **AlanEvren.xcodeproj** — Xcode projesi
- **Package.swift** — Swift Package
- **INSA_RAPORU.md** — inşa raporu (sahibin iç defteri)

## iCloud detay paketi

`AlanEvren_1000` iCloud klasöründe 10 detaylı dosya:
- App Store ilk 1000 hedefi
- Top 1000 seçim mantığı
- UI / mantık / etkileşim kartları
- Çift kapı + "yokla–var et" + "ince ilmek" eylem akışları

## Tech stack

- Swift 5.9 / SwiftUI / Xcode
- Swift Package Manager
- App Store Connect yayın hattı
- Python tarafı: kart üretici + içerik

## Durum

İnşa hattı kurulu. fert kataloğu büyüyor. App Store yayın için son hazırlık.

## NDA-altı tarafı

Alan dinamiği çekirdek matematik (`_core`) ve fert seçim algoritması — patent
+ lisans çerçevesi içinde.
